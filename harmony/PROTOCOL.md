# 掼蛋 局域网联机协议 v1.1（安卓 ↔ 鸿蒙 通用）

两端同一套协议，任何一端都能开房，另一端加入；支持**广播自动发现**、**掉线重连**、**出牌超时**。

## 传输层

| 用途 | 协议 | 端口 |
|---|---|---|
| 牌局数据 | TCP，行分隔 JSON（UTF-8，`\n` 结尾） | **48620** |
| 房间发现 | UDP 广播，明文 `GD?` / `GD!...` | **48621** |

房主是**权威端**：出牌判定、轮转、升级、超时托管都在房主侧计算；客户端只显示与提交意图。

## 牌编码

`[id, rank, suit]`：`id` 0~107 唯一；`rank` 2~14 为 2~A，15 小王，16 大王；`suit` 0♠ 1♥ 2♣ 3♦ 4 王。

## 房间发现（UDP 48621）

加入方广播：

```
GD?
```

房主应答（原地址回发）：

```
GD!掼蛋房间|48620|A1B2
```

即 `GD!` + 房间名 + `|` + TCP 端口 + `|` + 4 位房号。加入方在 1.5~2 秒内收集应答并列出房间，选中即用其中的 `ip`（报文源地址）和 `room` 连接。

## 连接握手

客户端 TCP 连上后**第一行必须发 hello**：

```json
{"t":"hello","room":"A1B2","seat":1}
```

- 首次加入：`room` 传空、`seat` 传 0，由房主分配 1/2/3
- 断线重连：带上上次的 `room` 与 `seat`，房主在 **90 秒**内保留该座位，可原座复位
- 房号不匹配或座位已被占用：房主按新客人分配空位；三位真人满员时回 `{"t":"full"}` 并断开

房主分配成功后回：

```json
{"t":"seat","seat":1,"room":"A1B2"}
```

## 客户端 → 房主

```json
{"t":"play","cards":[12,37,56]}
{"t":"pass"}
{"t":"ping"}
```

## 房主 → 客户端

状态快照（每次变化全量广播）：

```json
{
  "t":"state","lvl":2,"t0":2,"t1":2,"round":1,"turn":0,"lastSeat":2,
  "over":false,"result":"","gain":0,
  "hand":[[88,14,1],[3,2,0]],
  "seats":[{"n":27,"tag":"—","ai":false,"fin":false}, ...],
  "last":{"type":2,"key":9,"power":0,"size":2,"cards":[[51,9,0],[60,9,1]]},
  "fin":[0],"logs":["对家 出 对子"]
}
```

| 字段 | 含义 |
|---|---|
| `hand` | 只发给对应座位，其他座位为空 |
| `seats[i].n/tag/ai/fin` | 剩余张数 / 最近动作 / 是否 AI / 是否出完 |
| `last` | 中央待压牌型，`null` 为领出 |
| `fin` | 已出完座位顺序 |

## 出牌超时

房主对**真人座位**计时 **22 秒**：

- 领出方超时：自动出最小单张
- 跟牌方超时：自动「不出」

超时后写入日志并广播新状态，倒计时在牌桌中央显示为「乾位·你 剩 12s」。

## 规则

与单机完全一致，不做改动：两副牌、逢人配、同花顺、炸弹分级、天王炸、接风、双上 +3 / 一三 +2 / 一四 +1、打 A 收场。

## 已知限制

- 广播发现依赖同一局域网且路由器未开启 AP 隔离
- 重连只保留 90 秒，超时后座位交回 AI
- 无 TLS/鉴权，仅限可信局域网使用
